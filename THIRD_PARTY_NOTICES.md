# Componentes de terceiros

Este projeto utiliza pyHanko 0.37.0, distribuído sob licença MIT, e suas
dependências. Ao gerar uma versão para distribuição, preserve os avisos e
licenças aplicáveis às dependências incluídas pelo PyInstaller.

Projeto pyHanko:
https://pypi.org/project/pyHanko/

Também utiliza pypdfium2 5.14.0 (BSD-3-Clause ou Apache-2.0), que embute o
PDFium e bibliotecas de terceiros com licenças próprias, usado para achar área
livre no rodapé ao posicionar o carimbo da assinatura. Os textos completos
das licenças acompanham o pacote pypdfium2 (pasta `licenses` do dist-info).

Projeto pypdfium2:
https://pypi.org/project/pypdfium2/
